# 공개 방명록 연동 패키지 — 정우 · 서하 청첩장

이 패키지는 현재 청첩장의 06 / THE GUESTBOOK을 활성화합니다. 기존 RSVP 로직은 유지합니다.

## 포함 파일과 업로드 위치

**GitHub 저장소 최상위**에 다음 5개 파일을 업로드합니다.

- `index.html` — 기존 파일 덮어쓰기 (모든 기존 섹션 유지)
- `guestbook.js` — 신규
- `guestbook.css` — 신규
- `rsvp.js` — 기존 버전 유지용으로 동봉 (동일한 파일이 이미 있으면 교체 불필요)
- `rsvp.css` — 기존 버전 유지용으로 동봉 (동일한 파일이 이미 있으면 교체 불필요)

`Code.gs`는 **GitHub에 업로드하지 말고** Google Apps Script 편집기에 붙여 넣으세요.

### Google 설정 (필수)

1. **RSVP에서 실제 사용 중인 Google Sheets**를 열고 `확장 프로그램 → Apps Script`로 이동합니다.
2. 기존 `Code.gs`를 백업하고, 이 패키지의 `Code.gs` **전체 내용으로 교체**합니다. 기존 RSVP 핸들러를 보존하면서 공개 방명록 핸들러가 추가된 버전입니다.
   - 중요: 기존 RSVP에 이미 별도의 사용자 수정 코드를 적용했다면 **무작정 덮어쓰지 말고 병합**해야 합니다. 이 파일은 처음 제공한 기본 RSVP 서버 코드에 방명록 기능을 추가한 것입니다.
3. `setupGuestbook()`을 **한 번 실행**하고 Google Sheets / Google Drive 권한을 승인합니다. `GUESTBOOK` 시트와 `Wedding Guestbook Photos` 폴더가 자동 생성됩니다. 폴더 ID는 스크립트 속성으로 보관됩니다.
4. `배포 → 배포 관리 → 기존 웹 앱 수정(연필) → 새 버전 → 배포`를 선택합니다. 실행 사용자 `나`, 액세스 권한 `모든 사용자`(익명 허용). 기존 배포를 새 버전으로 업데이트하면 기존 `/exec` URL을 사용할 수 있습니다.
5. 새 웹 앱 URL로 바뀌었다면 `guestbook.js`와 `rsvp.js` 상단의 ENDPOINT를 모두 수정합니다.
6. GitHub에 5개 프런트엔드 파일을 올린 뒤 테스트합니다. **Google 배포와 웹 배포가 모두 끝나야** 동작합니다.

### GUESTBOOK 시트 구조

자동 생성되는 열:

`게시물 ID | 등록일 | 이름 | 메시지 | 사진파일 ID | 공개상태 | 요청 ID | 공개동의`

- 신규 게시물은 **즉시 `공개`** 상태로 저장됩니다.
- 부적절한 글을 내리려면 F열 `공개상태` 값을 **`숨김`**으로 수정하세요. 목록 새로고침 시 제외됩니다. 기존 글을 삭제할 때도 시트 행이나 사진 파일을 실수로 삭제하기보다는 `숨김` 처리하는 편이 안전합니다.
- 사진 원본은 Google Drive 폴더에 저장됩니다. 공개 사진은 **'링크가 있는 모든 사용자 보기'** 권한을 부여합니다. 따라서 사진 자체도 링크를 가진 사람이 볼 수 있습니다. 업로드 사진은 공개 목적 이외로 사용하지 마세요.
- 사진이 없는 글도 제출할 수 있습니다.
- 손님이 남긴 **이름·메시지·사진이 공개**된다는 동의 체크가 필수입니다.

### 테스트

1. **사진 없이** 테스트 이름·메시지를 제출 → `GUESTBOOK`에 한 행 추가 → 청첩장 하단 카드 표시 확인.
2. **사진 포함** 테스트 → Drive 폴더에 JPG 저장 → 공개 카드에 썸네일 표시 확인.
3. Google Sheets의 해당 행에서 F열을 `숨김`으로 변경 → 청첩장 다시 열어 해당 카드가 빠지는지 확인.
4. RSVP 신규/수정이 기존처럼 정상 동작하는지도 확인합니다.
5. 카카오톡 인앱 브라우저, Chrome, iPhone Safari에서 제출과 갤러리 조회를 테스트합니다.

### 제약 / 안전

- 공개 모드이므로 **게시물은 승인 없이 바로 노출**됩니다. 악의적 도배·부적절한 글·민감한 사진이 게시될 수 있어 운영 중 시트를 모니터링해야 합니다. 숨김은 다음 갤러리 조회부터 반영되며 이미 캐시되거나 저장된 내용은 되돌릴 수 없습니다.
- 이 구현은 허니팟 필드와 입력 검증을 포함하지만 **강력한 CAPTCHA·사용자 인증·IP 기반 제한은 제공하지 않습니다**. 공개 엔드포인트는 자동 제출 공격에 취약할 수 있습니다. 필요하면 승인형 공개나 별도 보안 프록시로 변경하세요.
- 이미지가 선택되면 브라우저에서 JPEG로 변환하고 크기를 제한한 뒤 업로드합니다. 최신 모바일 브라우저라도 HEIC 변환이 지원되지 않는 경우 JPG/PNG로 다시 업로드하도록 안내합니다.
- Google Drive의 공개 공유가 조직 정책으로 금지되어 있다면 사진 제출은 실패합니다. 이 경우 공개 폴더 접근 권한을 먼저 확인하세요.
- Google Drive 썸네일은 일부 브라우저/공유 정책에서 이미지 직접 표시가 막힐 수 있습니다. 썸네일이 실패하면 카드에서 이미지를 숨기며, 안정적인 사진 CDN/스토리지가 필요할 수 있습니다.
- Apps Script 할당량·업로드 한도에 영향을 받습니다. 소규모 청첩장 용도로 설계했습니다.
- 파일 소스의 Google 스크립트 `/exec` URL은 누구나 볼 수 있는 공개 클라이언트 주소입니다. **비밀번호나 Drive 공유 키를 HTML/JS에 넣지 마세요.**
